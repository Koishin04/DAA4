1. Mutations

The edit distance is the fewest insertions, deletions and replacements needed to turn strain A into strain B. Each change costs one; the table chooses the cheapest last step for every pair of prefixes.

2. Shared core

The longest common subsequence keeps letters in the same order but allows gaps. Unlike a substring, it does not need to be continuous.

4. Copied words

Shared words counts positions in A whose 12-letter window occurs somewhere in B. Repeated positions count separately. Rabin-Karp updates the window hash in constant time, then compares the letters to reject hash collisions.

5. Whom to test

Every infection link needs at least one tested endpoint. Tree DP compares the cost when a person is tested and when they are not; an untested person forces every child to be tested.
